# 04. Balance & QA

## 밸런스 기준
밸런스 감사 문서는 Slay the Spire를 장르 기준선으로 참고해 에너지당 공격·방어 효율, 카드 희귀도, 유물 효과의 지속성과 파워를 비교했습니다.

예시로 감사 문서에서 제시한 기준:
- 1에너지 기본 공격 약 6 피해
- 1에너지 기본 방어 약 5 블록
- 일반 등급 유물은 소규모 고정 보너스 중심
- 지속적인 에너지·드로우 증가는 높은 희귀도 또는 조건·대가가 필요

이는 프로젝트의 내부 밸런스 검토 기준이며, 보편적인 정답으로 제시하지 않습니다.

## 발견한 대표 리스크
- 0코스트 카드와 카드 회수 효과의 조합으로 발생할 수 있는 무한 루프
- 영구 누적되는 가시/성장 효과의 장기전 밸런스
- 턴 종료 피해 효과의 발동 타이밍 불명확
- 카드·유물 희귀도 대비 효과 파워 역전
- 클래스별 고유 유물 수량 불균형
- 코드에서 사용하는 상태효과와 밸런스 설정 데이터 간 불일치

## 개선 사례
개발 기여 히스토리와 밸런스 감사 문서에는 다음과 같은 조정 기록이 있습니다.
- 일부 시간술사 카드에 Exhaust 추가 또는 희귀도 조정
- 과도한 자원 생성 카드에 비용 또는 제한 추가
- 수호자 카드의 블록 수치 조정
- 사령술사 카드의 피해·자해 수치 조정
- 일부 유물의 발동 시점과 희귀도 재조정
- 몬스터 HP 및 공격 수치 재검토

## QA 개선 사례
- 맵 복귀 시 스크롤 위치 오류
- 세이브/로드 이후 선택 가능한 노드가 표시되지 않는 문제
- 로드 후 이전 층으로 회귀할 가능성
- 보상 화면에서 하위 카드 UI에 마우스 이벤트가 전달되는 문제
- 한글 폰트 및 카드 텍스트 가독성 문제

## 기획자의 문제 해결 과정
문제 발견 → 재현 조건 정리 → 플레이 경험에 미치는 영향 판단 → 우선순위 지정 → 수정 방향 제안 → 수정 후 재검증.

실제 포트폴리오에는 각 사례의 전/후 스크린샷이나 재현 영상이 있으면 함께 첨부합니다.
