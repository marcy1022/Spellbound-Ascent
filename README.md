# Spellbound Ascent
### 다크 판타지 로그라이크 덱빌더 | 게임 시스템·콘텐츠 기획 포트폴리오

> 카드 조합과 클래스별 자원 운용을 중심으로 설계한 턴제 로그라이크 덱빌더 프로젝트입니다.

- **장르:** 로그라이크 덱빌더 / 턴제 카드 전투
- **엔진·개발 환경:** Unity 6 (기획 점검 문서 기준), 실제 저장소 설정과 대조 필요
- **프로젝트 형태:** [개인 프로젝트 여부 확인]
- **진행 상태:** 플레이 가능한 프로토타입 / 최종 폴리싱 미완료
- **기획·검토 기간:** 2026.11 문서 기록 기준
- **담당:** 게임 콘셉트·시스템·콘텐츠·밸런스·UI/UX 개선 기획 및 AI 협업 검토 [실제 참여 범위 확인]

## 한눈에 보기
Spellbound Ascent는 4개 클래스의 고유 자원과 카드 시너지를 중심으로, 3개 액트를 진행하는 로그라이크 덱빌더입니다. 프로젝트 문서에는 카드 143장, 적 36종, 유물 25개, 포션 10종, 이벤트 8개, 상태효과 13종의 현황이 기록되어 있습니다. 이는 2026-11-09 점검 문서 기준이며, 현재 공개 빌드와 일치하는지 확인이 필요합니다.

## 핵심 기획 포인트
- **클래스 정체성:** 화염술사(잔불 축적·폭발), 수호자(방어·성장/가시), 시간술사(드로우·에너지 조작), 사령술사(자해·독·영혼 테마)
- **전투 구조:** 턴 시작 → 카드 사용 및 자원 관리 → 턴 종료 효과 → 적 행동
- **런 구조:** 3개 액트, 각 액트 15층의 노드형 맵
- **콘텐츠:** 카드·적·유물·포션·이벤트와 카드/유물/포션 도감
- **개선 반복:** 플레이 중 문제 발견 → 기획 검토 → 우선순위 설정 → 수정 요청 및 재검증

## 대표 기획 사례
1. 화염술사의 핵심 메카닉을 단순 화상 지속 피해에서 **잔불(Ember) 축적 후 폭발하는 자원 운용형 플레이**로 재설계했습니다.
2. 시작 덱을 8장으로 유지해 덱 압축이라는 장르 핵심 선택을 보존했습니다.
3. 클래스 선택 화면을 즉시 시작 방식에서 캐릭터 미리보기 후 확정하는 흐름으로 개선했습니다.
4. 카드 도감의 필터·정렬·강화 전후 비교, 카드 프레임과 텍스트 가독성, 포션 툴팁 등 정보 전달 UX를 개선하도록 기획했습니다.
5. QA 및 밸런스 감사에서 무한 루프, 과도한 자원 생성, 카드 등급 대비 효율 문제 등을 식별하고 수정안을 정리했습니다.

## 현재 상태와 한계
