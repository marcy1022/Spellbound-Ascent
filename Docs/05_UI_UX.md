# 05. UI/UX Design

## 주요 개선 방향
### 클래스 선택
기존 텍스트 중심의 클래스 선택에서 클래스 아이콘 선택, 대형 일러스트 미리보기, 클래스 특성 및 마스터 스킬 설명, 시작 확정 버튼으로 이어지는 흐름을 제안·반영한 기록이 있습니다.

### 카드 도감
- 클래스 탭, 필터 및 정렬
- 강화 전후 비교 토글
- 2열에서 3열 그리드로 정보 밀도 개선
- 카드 세로 비율 및 텍스트 마진 조정
- 코스트 젬과 숫자 표시 통일

### 전투 카드 핸드
- 겹쳐진 부채꼴 형태로 카드 배치
- 선택/호버 카드 확대 및 전면 표시
- 카드 비율 통일
- 코스트 표시와 텍스트 정렬 통일

### 포션 및 상태효과
- 텍스트 위주의 포션 표시를 아이콘 중심으로 변경
- 포션에 이름과 효과를 확인할 수 있는 툴팁 제공
- 상태효과 이름과 수치를 더 쉽게 인지하도록 배치 개선

## 기획 의도
카드 로그라이크는 플레이어가 카드의 비용·효과·상태·시너지를 빠르게 읽어야 하므로, 정보의 우선순위와 가독성이 전투 판단에 직접 영향을 줍니다.

## 증빙 권장
- 클래스 선택 화면 전/후
- 전투 카드 핸드 전/후
- 카드 도감 전/후
- 포션 툴팁 및 상태효과 표시
