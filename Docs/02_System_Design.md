# 02. System Design

## 런 및 맵
최종 기획서에는 3개 액트, 액트별 15층 구조가 정의되어 있습니다.
- Act 1: 하층부 — 잿빛 회랑
- Act 2: 중층부 — 수정 서재
- Act 3: 최상층 — 왕좌의 간

노드 유형: 일반 전투, 엘리트, 상점, 이벤트, 휴식, 보물, 보스.
맵 생성 규칙은 층별 2~4개 노드, 다음 층 1~2개 노드 연결, 경로 단절 방지, 보스 15층 고정으로 기획되어 있습니다.

## 전투 턴 구조
1. 턴 시작: 에너지 충전, 카드 드로우, 시작 효과 처리
2. 플레이어 행동: 카드 사용, 포션 사용, 마스터 스킬 사용
3. 턴 종료: 미사용 카드 버리기, 턴 종료 효과 처리
4. 적 행동: 표시된 의도에 따라 공격·방어·버프 등 수행

기획서 기준 기본 에너지는 턴당 3, 기본 드로우는 5장, 최대 핸드는 10장입니다. 실제 적용 수치는 게임 빌드와 대조해야 합니다.

## 클래스 정체성
| 클래스 | 핵심 방향 | 기획상 특징 |
|---|---|---|
| 화염술사 | 잔불 축적과 폭발 | Ember 자원을 쌓고 마스터 스킬로 소비 |
| 수호자 | 방어와 반격 | Growth/Thorns 등 방어 기반 누적·감쇠 |
| 시간술사 | 드로우와 에너지 조작 | Haste 및 카드 회수/시간 조작 |
| 사령술사 | 자해·독·영혼 | 체력 리스크를 활용하는 고위험 고수익 방향 |

## 카드·유물 데이터 설계
최종 기획서는 카드 JSON에 id, 클래스, 타입, 코스트, 희귀도, 대상, 효과 배열, 강화 효과, 키워드 등을 두도록 정의합니다. 유물도 트리거와 복수 효과 배열을 갖는 구조입니다.

기획 의도: 카드·유물 콘텐츠를 데이터 기반으로 관리해 콘텐츠 추가, 밸런스 조정, AI를 활용한 초안 생성 및 검토를 체계화합니다.

## 기획 시 고려한 예외 규칙
- 드로우 파일이 부족하면 버리기 더미를 섞어 보충
- 드로우 파일과 버리기 더미가 모두 비면 드로우 생략
- 카드 효과 배열은 정의된 순서대로 적용
- Exhaust 카드는 전투 종료 후 덱 복귀
- 상태효과는 지속형·스택형·감쇠형으로 구분

※ 위 규칙은 최종 기획서에 기록된 규칙이며, 현재 코드에서 전부 동일하게 작동하는지는 별도 테스트가 필요합니다.
