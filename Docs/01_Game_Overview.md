# 01. Game Overview

## 프로젝트 개요
Spellbound Ascent는 다크 판타지 세계관을 바탕으로 한 턴제 로그라이크 덱빌더입니다. 플레이어는 클래스를 선택하고, 전투·이벤트·상점·휴식 노드를 거치며 카드를 획득·강화하고 유물과 포션을 조합해 액트의 보스를 공략합니다.

## 핵심 플레이 경험
- 매 전투에서 제한된 에너지와 핸드 안에서 카드 사용 순서를 판단합니다.
- 클래스별 고유 자원과 카드 시너지로 서로 다른 빌드를 구성합니다.
- 맵 경로와 보상 선택을 통해 런마다 다른 전략을 만듭니다.
- 카드·유물·포션의 조합을 통해 장기적인 성장 방향을 선택합니다.

## 핵심 루프
1. 맵에서 다음 노드를 선택
2. 전투·이벤트·상점·휴식 진행
3. 보상으로 카드·골드·유물·포션 획득
4. 덱과 자원 운용 전략 조정
5. 보스 격파 후 다음 액트 진입
6. 최종 보스 도전 및 런 결과 확인

## 설계 방향
- 클래스마다 플레이 방식과 자원 관리의 차이를 명확히 합니다.
- 카드 효과는 데이터 구조로 관리해 콘텐츠 확장과 밸런스 조정을 용이하게 합니다.
- 모바일 세로 화면을 전제로 카드 정보와 전투 UI의 가독성을 개선합니다.
